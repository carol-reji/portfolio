# carolreji.github.io

Carol Reji — mechanical engineering portfolio.

## Deploy
Drag everything in this folder into a public GitHub repo named exactly `<username>.github.io`, commit, and it is live at https://<username>.github.io in about a minute.

## Files
- index.html — desktop home (drag the windows)
- project-firefly.html / project-tesla.html / project-baja.html — full case studies
- work.html — all eight projects
- about.html — long version + contact
- support.js — required, keep it next to the pages
- docs/ — supporting calculations linked from the Baja page

## Editing
Copy changes are safe to make directly: open the file on GitHub, click the pencil, find the sentence, edit, commit. Everything is plain HTML with inline styles — no build step.
Layout or new-section changes are easier to hand back to Claude.
